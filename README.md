# E-Commerce Sales Analyzer (PS 29)

Analyses order data from a CSV file: total revenue, units sold,
best-selling products and category-wise revenue, with charts.

## Requirements
pip install pandas matplotlib

## How to run
python ecommerce_sales_analyzer.py orders.csv

## Menu
1. Summary
2. Category-wise revenue (pie chart)
3. Top 5 products (bar chart)
4. Exit
